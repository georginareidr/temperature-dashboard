# Temperature Dashboard

A tool for converting temperature scales.

## Features

- Celsius
- Fahrenheit
- Kelvin

## How to Use

Enter a temperature and select its original unit.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
